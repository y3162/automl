## 機能要件

| ID | 要件 |
|---|---|
| `EX-F-001` | 初版では確保済みの計算機上で、設定で指定した学習・評価を公開APIから別プロセスとして起動できること。評価のみの実行で新たに測定する場合は、指定したモデル状態または予測結果をEvaluatorに渡すこと |
| `EX-F-002` | 枝と実行に一意で安定したIDを割り当て、枝内の順序と分岐元を記録し、各地点から起点までの経路と、その地点から分岐した枝をたどれること。同じ枝では一度に一実行を受け付け、別の枝では並行実行できること |
| `EX-F-003` | 枝が空き、その枝で一度も学習を開始していないと確認できれば、先の失敗・中断の履歴を残して同じ枝で新規学習を再試行できること。学習開始後の続行は、枝内で最後に学習を開始した実行の有効な保存点から同じ枝の末尾に追加すること。学習を開始した後で過去の地点や共通の起点からやり直す場合は、設定が同じでも新しい枝を作成すること |
| `EX-F-004` | 実行と各処理の状態・結果を個別に記録すること。処理中の失敗・中断でも、それまでに確定した対象別の結果、学習経過、ログ、成果物を保持し、それらを使った後続の実行を追跡できること |
| `EX-F-005` | 実際に適用された設定、コードと実装の版、データやモデル状態の参照、TrainerやEvaluatorから渡された結果・ログ・成果物を、それぞれの実行に関連付けて記録・検索できること |
| `EX-F-006` | 呼び出し側が報告した判断と、その判断に用いた評価結果を関連付けて記録できること |
| `EX-F-007` | プロジェクト全体の正本をコピーした移行先で、移行元に接続せずに、同じ実行IDから枝・実行・評価結果・保持対象の成果物を辿れ、DBの記録、ログ、成果物の内容と関係を検証できること。不足や不一致があれば、対象と理由を特定できること |
| `EX-F-008` | 外部の呼び出し元が、公開APIから枝と実行履歴を取得し、指定した地点から枝を作成できること。その枝で実行を起動し、実行IDを使って状態と結果を取得できること |
| `EX-F-009` | 同じ計画の並行評価が進行中であれば、学習成功後も実行中として追跡し、その評価の完了条件を確認して実行の成否を確定できること。後日追加した評価は新しい実行IDで追跡し、評価対象を辿れること。プロジェクト内の成果物を使った場合はその生成元の実行を、外部の予測ファイルを取り込んだ場合は受付時の入力を特定できること |
| `EX-F-010` | 受付済みの実行IDを指定して停止を要求できること。プロセスの起動を取り消せた場合は実行を中断とし、起動済みの場合は進行中の学習・評価に要求を伝えること。安全な停止を確認した処理に中断を記録し、完了済みの処理結果を保持すること。並行する一方がすでに失敗している場合は、他方の中断を確認して実行全体を失敗とすること。逐次実行で学習を中断した場合は実行全体を中断とし、未開始の後続評価を理由付きでスキップすること。中断した学習については再開元に使える保存点IDまたは再開できない理由を示すこと |
| `EX-F-011` | 枝作成・起動・再開に任意の要求IDを指定できること。同じ要求ID・同じ内容の再送には実行終了後も初回のIDを返し、枝や実行を二重に作成しないこと。分岐と起動を一度に依頼した場合は初回の枝IDと実行IDの両方を返すこと。同じ要求IDで内容が異なる場合は、元の要求を特定できる理由を返して拒否すること |
| `EX-F-012` | 同じ計画の学習と評価を並行して実行中に一方が失敗しても、他方が単独で続けられる場合は原則として続行し、その間は実行全体を実行中とすること。他方が成功しても実行全体は失敗とし、各処理の結果と成果物を保持すること。逐次実行で学習が失敗した場合は、未開始の後続評価を理由付きでスキップし、その時点で実行全体の失敗を確定すること |
| `EX-F-013` | タスク側が選んだ保存点IDを評価・分岐に使い、実際に利用したIDを記録すること。過去の成績と、現在利用できる保存点の両方を取得できること。学習後の評価候補が0件の場合は、実行中のタスクが終了前に実験の意図に沿って見送りか失敗かと理由を報告し、状態と履歴からその理由を確認できること |
| `EX-F-014` | 指定IDの保存点を単位として状態の実体を削除し、ID・評価・使用履歴を残すこと。使用中の削除、削除と利用の競合、削除途中の停止・再依頼を扱い、移行先でも削除済み・削除中・保持対象の欠落を識別できること。`latest` は現在保持する直近の再開可能な保存点に解決すること |
| `EX-F-015` | 公開APIから、最終モデルに至る再開経路と各区間の記録、やり直しを含む全実行の記録を取得できること。新しい枝の学習区間と初期化元をたどれること。集計と描画はタスク側が担うこと |
