## データ要件

| 対象 | 内容 |
|---|---|
| 枝 | 枝IDと、起点または分岐元の枝ID・実行地点。保存点を指定して分岐した場合はその保存点の参照 |
| 実行 | 実行ID、所属する枝、枝内での順序、開始・終了日時、終了状態と理由。プロセスの起動と区別できる学習開始の記録。再開時は再開元の実行とチェックポイントの参照 |
| 要求IDを指定した受付 | 呼び出し側の要求ID、操作と依頼内容を照合できる情報、初回に発行した枝ID・実行IDのうちその操作が返すもの |
| 適用条件 | 実際に適用した設定、実行コードを特定する情報、プロジェクト・タスクが依存環境の照合対象とした項目の実行時の値、各実装の版、Datasetの版・分割、必要なTransformの再現情報、モデルの初期状態。既存のモデル状態を初期値に使った場合は初期化元の保存点と、部分引き継ぎで指定した名前 |
| 処理単位の記録 | 学習や評価の状態、指標と結果、ログ、チェックポイントなどの成果物への参照。処理が失敗・中断した場合は各処理の終了理由。評価が未開始でスキップまたは失敗した場合は、前段の学習の終了状態や、候補0件に対して実行中のタスクが報告した扱いと理由。評価のみの実行では、評価対象のモデル状態や予測結果への参照 |
| 保存点 | 生成元の実行ID、保存点ID、学習順と進捗、対応するモデル・学習状態、使用分の範囲、保持・削除中・削除済みの状態。削除後も評価結果と利用した実行への参照を保持する |
| 結果の利用履歴 | Experimentに報告された判断のID・内容、参照した評価結果、後続の実行がある場合はその参照。比較の根拠を残す場合は、DBまたはドキュメントで各評価を特定できる実行ID・評価IDの組やリンクと、判断理由を対応付けることを推奨する |
| 移行に必要な情報 | 全枝の実行履歴、DBの記録、ログ、確定設定、保持対象の成果物と実行との対応、および内容の検証情報。外部コーパスなどは移行先で同じ版を特定できる参照 |
