## データ要件

| 対象 | 内容 |
|---|---|
| 枝 | 枝IDと、起点または分岐元の枝ID・実行地点。分岐時に学習状態を引き継いだ場合は、そのチェックポイントの参照 |
| 実行 | 実行ID、所属する枝、枝内での順序、開始・終了日時、終了状態と理由。再開時は再開元の実行とチェックポイントの参照 |
| 適用条件 | 実際に適用した設定、実行コードや依存環境を特定する情報、各実装の版、Datasetの版・分割、必要なTransformの再現情報、モデルの初期状態 |
| 処理単位の記録 | 学習や評価の状態、指標と結果、ログ、チェックポイントなどの成果物への参照。評価のみの実行では、評価対象のモデル状態や予測結果への参照 |
| 結果の利用履歴 | 判断を識別できる情報、参照した評価結果、判断に対応する後続の実行などの記録 |
| 移行に必要な情報 | 全枝の実行履歴、DBの記録、ログ、確定設定、保持対象の成果物と実行との対応、および内容の検証情報。外部コーパスなどは移行先で同じ版を特定できる参照 |
