## データ要件

| 対象 | 内容 |
|---|---|
| 学習手順と実行設定 | 実装を特定できる参照と版、実際に適用した設定、指定されたDataset・Transform・Modelの参照や版 |
| 開始方法 | 新規開始、別の試行のモデル状態を使った初期化、同じ試行の再開。初期化・再開に使用した保存点IDと、その生成元の実行を辿れる参照 |
| 保存点の内容 | 同じ地点のモデル状態・学習状態・進捗。学習状態の内容と内部形式は、タスクの再開条件に従ってTrainerの個別実装が定める。例として、データ位置、乱数、最適化器、スケジューラの状態がある。ワーカーごとの状態が必要な場合は、対応するプロセスも特定できるようにする |
| 進捗と結果 | 試行識別子、各記録時点の進捗とその単位、ロス・統計量などの指標名と値、成果物への参照、終了状態と理由。指標と記録頻度は学習手法に応じて個別実装が決める |
| 再現に必要なデータの参照 | 実際に利用したデータの版・分割、必要なTransformの再現情報、実行とデータ使用記録の対応。分散学習ではプロセスごとの使用分を、保存点があればそこに反映された使用範囲を特定できる情報 |

再開は、保存点に対応するモデル状態と学習状態を組み合わせ、その時点から学習を継続する。チェックポイントを初期値として使う新規試行では、新しい試行の進捗と学習状態を開始し、モデル状態の取得元を記録する。
