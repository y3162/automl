## データ要件

| 管理対象 | DBで管理するメタデータ |
|---|---|
| **データ実体** | 元データ・生成物の識別子、版、保存先、形式、内容の検証情報 |
| **レシピ定義** | DBから取得できる選択・生成手順、生成器の版、入力仕様、抽選条件、必要な実行環境への参照 |
| **生成サンプル** | レシピの版と、その使用時に確定した入力のID・版、抽選結果や適用パラメータを特定できる情報。DatasetはこれらをDBから取得できる |
| **データセット版** | 固定した構成、分割、選択条件。動的生成の場合は入力素材と生成方針の固定版 |
| **使用記録** | 実行ID、使用したサンプルのID・版、各回の使用を区別して再送を識別できる情報。手法で意味を持つ順序と反復 |
| **バッチの構成** | バッチを使う場合、その実行内でバッチを識別する情報、呼び出し側が定めた構成、各使用分とプロセスとの対応。全体の記録の完了と未受領の範囲を判別できる情報 |
| **保存点との対応** | 再開に対応する場合、有効な保存点のIDと、そこに反映された使用履歴の範囲 |
| **教師信号・対応関係** | 教師信号がある場合は、ラベルや正解データなどの版・由来と元データとの対応関係 |
