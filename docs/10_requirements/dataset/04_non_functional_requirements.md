## 非機能要件

| 観点 | 要件 |
|---|---|
| **再現性** | 固定済みの版を再取得できること。実験を実装するエージェントは、学習中に選択・生成したデータの使用履歴を復元し、各サンプルの内容をプロジェクト・タスク所定の一致基準で照合できるようにすること |
| **信頼性** | 保存途中のデータを利用可能として返さないこと。同じ登録要求の再送で重複登録しないこと |
| **同時利用** | 複数の学習処理から読み込み・登録しても、記録の整合性を保てること |
| **性能** | データ量や並列数などの想定規模と、その規模で許容する読み込み・登録負荷はプロジェクト・タスクごとに定める。実験を実装するエージェントは、その条件下で所定の性能を満たすこと |
| **拡張性** | 新しいデータ形式・生成器・保存先を追加できること |
| **保持・追跡** | 再利用対象のレシピが依存するデータや生成器の版を追跡できること |
