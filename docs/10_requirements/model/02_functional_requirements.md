## 機能要件

| ID | 要件 |
|---|---|
| `MD-F-001` | Dataset・Transformと同じ方式で実装の参照・版と構成設定を指定し、モデルの種類に共通の公開APIから該当するモデルをビルドできること |
| `MD-F-002` | 新規構築時に、指定された初期化条件に従ってモデルのパラメータを初期化できること |
| `MD-F-003` | 対応する実装・構成でモデルを構築し、指定されたチェックポイントから重みとモデル固有の状態を完全復元できること |
| `MD-F-004` | 指定された実装・版の解決に失敗した場合や、設定またはチェックポイントが指定したモデルと適合しない場合は、原因を呼び出し側に伝えられること |
| `MD-F-005` | 部分引き継ぎでは、個別実装と初期化設定に従い、指定された重み・モデル固有の状態をチェックポイントから引き継ぎ、構築先の残りを指定どおり初期化できること。実際に引き継いだ箇所と初期化した箇所を呼び出し側に返すこと。指定箇所の一つでも引き継げない場合は構築を失敗とし、該当箇所と理由を伝えること |
| `MD-F-006` | 共通の公開APIから、構築済みモデルの現在の重みと、同じ地点のモデルを完全復元するために必要なモデル固有の状態を取り出せること |
