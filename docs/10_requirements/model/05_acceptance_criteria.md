## 要件を満たしたと判断する基準

| ID | 確認する状況と期待結果 | 関連要件 |
|---|---|---|
| `MD-A-001` | 同じタスクのTrainer・Evaluatorが求める操作と入出力を満たすモデル実装を追加する。Modelの共通部分を編集せずに、実装の参照・版と構成設定を切り替えるだけで、両方のモデルをビルドし、同じ学習・評価手順で利用できる | `MD-F-001` |
| `MD-A-002` | 新規構築時に初期化条件を指定すると、その条件どおりにパラメータが初期化される | `MD-F-002` |
| `MD-A-003` | 学習で重みと正規化統計量が初期値から変わったモデルの現在の状態を公開APIで取り出し、保存点を作る。対応する実装の版・構成で別のモデルを構築して完全復元すると、重みと統計量の双方が取り出した時点の値に一致する | `MD-F-001`、`MD-F-003`、`MD-F-006` |
| `MD-A-004` | 存在しない版、またはモデルと適合しない設定やチェックポイントを指定した場合、呼び出し側が失敗の原因を確認できる | `MD-F-004` |
| `MD-A-005` | 旧モデルから一部の層を引き継ぎ、ヘッドの追加・削除と既存層の一部の再初期化を含むモデルを構築する。構築結果が指定の構造を満たし、引き継いだ重みは保存値に一致し、残りの重みは指定の条件に従って初期化される。初期化結果から、引き継いだ部分と初期化した部分を確認できる | `MD-F-005` |
| `MD-A-006` | 引き継ぐよう指定した重みやモデル固有の状態がチェックポイントにない、または構築先と適合しない場合、呼び出し側が該当箇所と理由を確認できる | `MD-F-004`、`MD-F-005` |
| `MD-A-007` | 初期値と異なる正規化統計量を持つ特徴抽出器を、同じ保存点から二通りの設定で引き継ぐ。両方で重みは保存値に一致し、統計量は引き継ぎを指定した場合は保存値、再初期化を指定した場合は指定した初期値に一致する。呼び出し側に返した内訳も各結果と一致する | `MD-F-005` |
| `MD-A-008` | 一部の構成項目を省略し、チェックポイントを指定して実行する。後日、実行IDから実際に使った実装の参照・版、省略した項目の既定値を含む確定設定、読み込んだモデル状態を特定できる | `MD-F-001`、`MD-F-003` |
