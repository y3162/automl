## データ要件

| 対象 | 内容 |
|---|---|
| モデル実装の参照 | クラスパスや公開名、バージョンなど、使用する実装と版を特定できる情報 |
| モデル構成 | 使用する実装の構築に必要な設定。項目・既定値・許容値は個別実装が定める。実行履歴には既定値を含む確定設定を実装の参照・版と対応付ける |
| 初期化条件 | 初期化方法と、その方法に応じて必要となる設定。乱数シードなどは、指定された初期化方法で必要な場合に用いる |
| モデル状態 | 取り出した時点の重みと、推論に使う正規化層の学習済み統計量など、対応する実装・構成での完全復元に必要な状態 |
| チェックポイント | ロードするモデル状態の識別情報または参照と、ロードの可否を判定するために必要な情報 |
| 部分初期化 | 初期化元のチェックポイント、重み・モデル固有の状態の引き継ぎ条件、構築先の残りの初期化条件。結果には、実際に引き継いだ箇所と、新規に初期化または再初期化した箇所を特定できる情報を含む |
