## 機能要件

| ID | 要件 |
|---|---|
| `TR-F-001` | 呼び出し側から渡されたデータに前処理・合成を適用し、処理結果を返せること |
| `TR-F-002` | TransformをDatasetから独立して呼び出し、学習中と単独実行時で同じ処理の実装と設定を利用できること |
| `TR-F-003` | Transformを個別に呼び出せ、必要に応じて結果を後続処理に渡せること |
| `TR-F-004` | 前処理・合成が不要な場合に、受け取ったデータをそのまま返す恒等変換を利用できること |
| `TR-F-005` | 各回の処理の版と実際に適用した条件を含む再現情報を呼び出し側に返せること。学習に使った生成サンプルでは、元の入力と同じ版の実装・依存先を用意すれば、DBから取得したレシピだけで再適用できること |
| `TR-F-006` | 設定で指定されたTransform実装を、共通の公開APIから利用できること。契約に適合する実装の追加時は、Transformの共通部分の編集を要しないこと |
| `TR-F-007` | 複数のTransformを使う場合、呼び出し側が各段の版・適用条件と処理順をレシピに記録でき、中間結果の実体を保存しなくても、元の入力から順に再適用して最終結果を再生成できること |
| `TR-F-008` | プロジェクト・タスクが検索項目に指定した適用条件について、Transformが実際の値を呼び出し側に返し、Datasetを通じてその値で学習に使ったサンプルを検索できること |
