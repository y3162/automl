## 要件を満たしたと判断する基準

| ID | 確認する状況と期待結果 | 関連要件 |
|---|---|---|
| `TR-A-001` | 呼び出し側が用意した入力と設定を渡すと、TransformはDBやrawデータの保存先に接続せず、前処理・合成の仕様どおりの結果を返す | `TR-F-001`、`TR-F-002` |
| `TR-A-002` | 単独実行で確認したTransformを、同じ実装・設定で学習中にも呼び出せる | `TR-F-002` |
| `TR-A-003` | Transformを単独で呼び出し、返された結果を後続処理に渡せる。例として、対象となる全データから求めた統計量を後続の正規化処理に渡す | `TR-F-003` |
| `TR-A-004` | 教師信号を伴う入力と伴わない入力のいずれでも、恒等変換はデータ本体と渡された付随情報をそのまま返す | `TR-F-004` |
| `TR-A-005` | 実行時に処理条件を抽選するTransformを、元の入力と初回実行時に返された再現情報で再実行すると、当初の結果と定めた一致条件を満たす | `TR-F-005` |
| `TR-A-006` | 新しい前処理または合成の実装を追加し、その実装を設定で指定すると、Transformの共通部分を編集せずに同じ公開APIから処理を使える | `TR-F-006` |
| `TR-A-007` | 音声の切り出しとノイズ混合を順に行い、中間音声を保存せずに学習に使う。別プロセスでDatasetのDBからレシピを読み戻すと、音声・ノイズのIDと版、処理順、各段の版、切り出し位置・長さ、混合条件が分かる。指定版の入力と実装で再適用すると、最終音声がタスク所定の一致基準を満たす | `TR-F-003`、`TR-F-005`、`TR-F-007` |
| `TR-A-008` | S/N比を検索項目とし、同じ抽選設定で3 dBと12 dBのサンプルを生成して学習に使い、別の3 dBのサンプルは先読みだけにする。Datasetで「この実行で使用、かつ0〜5 dB」を指定すると、実際に使った3 dBのサンプルだけが得られる | `TR-F-008` |
