## 機能要件

| ID | 要件 |
|---|---|
| `EV-F-001` | 評価手順の実装と設定を指定し、同じ公開APIから学習中にも単独でも評価を実行できること |
| `EV-F-002` | 指定された対象に評価を適用し、評価条件、指標と集計結果、完了状態を呼び出し側に返せること |
| `EV-F-003` | 評価中のエラーに対する再試行、打ち切り、失敗を報告して残りを続行するなどの対応を設定で選べること |
| `EV-F-004` | 実際に集計した対象と、失敗・除外した対象およびその理由を特定できること。評価設定が定める完了条件の充足を示し、条件未達の集計値を返す場合は暫定値と分かること |
| `EV-F-005` | 学習中・単独評価のどちらでも、個別実装が生成したログに評価IDを添え、評価中にも終了時にもExperimentの共通の受け口に渡せること。途中で停止しても受領済みのログを元の評価IDから参照できること |
| `EV-F-006` | タスクが定めた評価単位の結果が確定するたびに、学習中・単独評価で共通の受け口を通じてExperimentに渡すこと。評価IDから確定済みの各結果を取得でき、各結果から対象、実際に評価に使ったデータ、評価したモデル状態または入力予測を辿れること。ログを出さない場合や評価全体が未完了の場合も同じ要件を満たすこと |
